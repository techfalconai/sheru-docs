# Sheru Documentation

This repository contains documentation for the Sheru platform, separate from the main code repository.

## Structure
- `customer/user-guide.md` — End-user documentation (MDM enrollment, TPRM vendor tracking, AI governance)
- `engineer/sop.md` — Operations and deployment runbooks
- `engineer/zendesk-integration.md` — Zendesk portal integration (subdomain: `epicit.zendesk.com`)
- `support/zendesk-portal.md` — Customer support SOPs and escalation workflows
- `tprm-plan.md` — Third Party Risk Management module documentation
- `mdm-plan.md` — Mobile Device Management (Intune + Kandji + Jamf) documentation
- `agent-plan.md` — Lightweight MDM agent architecture documentation
- `architecture.md` — System architecture reference
